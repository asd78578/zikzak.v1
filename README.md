Чем микросервис отличается от монолита?
Это одно приложение, где всё внутри одного кода и одного запуска.
Это система из нескольких маленьких сервисов, каждый делает свою задачу.
Для чего нужен Docker?
Docker — это инструмент для запуска приложений в контейнерах.
Что такое REST API?
REST API — это способ общения между клиентом и сервером через HTTP.
В чем разница между POST и GET?
GET — получить данные
POST — отправить данные
GET → читаю
POST → создаю
PUT → заменяю
PATCH → подправляю
DELETE → удаляю
